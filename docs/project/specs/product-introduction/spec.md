# SpecTrail 产品介绍与首次使用

中文产品介绍站部署于 Cloudflare Pages，正式入口为 `https://spec-trail.pages.dev/`。首页与 Skill、工作台、原型管理三个独立页面使用一致导航，并解释各自用途、使用时机和使用入口。

## 模块与阅读路径

- Skill 是默认使用入口：给 Codex、Claude Code 等编码 Agent 提供仓库内工作流，用 Git 保存需求、方案、任务、验证和验收记录。
- OpenFolio 工作台是可选的独立部署服务，供用户只读已提交推送的工程记录。介绍页说明获得实例地址、自己的 GitHub token 与仓库读取权限等使用前提，并提供真实界面截图；源码访问权限是自行部署的前提。
- 原型管理是随 Skill 分发的可选部分，使用示例数据演示页面与组件设计，维护项目当前入口和 Change 固定版本。页面提供公开交互示例与启用提示词，版本管理和托管细节位于进阶部分。

首次使用从目标 Git 项目中的安装开始，再在 Agent 对话中接入项目，随后说明第一项改动和验收期待。完整安装环境推荐 Git、Node.js 24 或更新版本，以及 Codex 或 Claude Code。

安装选项支持 Codex 与 Claude Code。Claude Code 的复制安装同时选择 `universal claude-code`，生成现有脚本需要的项目共享 `.agents/skills/spec-trail/` 和客户端 `.claude/skills/spec-trail/` 入口。公开 README 和站点命令保持一致。

## 操作与可读性

页面提供命令和提示词复制。成功反馈分别指向终端或项目的 Agent 对话；剪贴板被拒绝时提供可手动复制的只读文本与手机、桌面操作说明。示例模块可切换，手机导航支持关闭和 Escape 焦点恢复，FAQ 与部署摘要支持键盘展开；无 JavaScript 时核心内容、导航和两个安装命令仍可读取。

## 内容与发布边界

Change 先解释为一次有目标、范围和验收条件的改动，Specs 解释为当前已实现并验证的能力说明。介绍站、工作台真实截图和使用模拟数据的原型分别标明用途；介绍站不提供工作台登录。已发布原型由对应托管服务持续保存，页面不作永久可用承诺。

站点为静态产物，生产发布沿用 Cloudflare Pages 项目 `spec-trail`。构建仅上传网站白名单文件和摘要元数据，不发布工程记录、分发技能或凭据；网站相关 main 推送触发生产发布，开发分支提供预览，PR 运行静态检查。
