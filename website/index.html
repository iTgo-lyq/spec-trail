只安装 Skill 可以使用吗？

可以。Skill 在编码 Agent 中执行，使用 Git 和项目内文档保存工作流。OpenFolio 提供浏览器阅读入口，原型管理则按需启用。

工作台会替 Agent 修改任务吗？

工作台读取中心 Git 已推送的记录。需求、任务和流程状态由 Agent 在仓库中维护，提交推送后再刷新工作台。

原型和真实业务系统是什么关系？

原型使用示例数据演示页面和组件交互。它为需求讨论与设计验收提供参考；业务实现继续在项目的工程流程中完成。

工程记录和公开原型的权限一样吗？

工程记录按你的 GitHub token 和仓库权限读取。已经发布的原型可以公开分享，准备发布时应使用适合公开展示的内容。

项目迁移后，工程历史如何保留？

Specs、Change 文档和归档随 Git 仓库保留。托管原型的固定版本由对应存储服务保留，Git 兜底的单 HTML 产物随仓库和归档保存。
